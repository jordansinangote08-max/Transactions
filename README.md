# Smart Card Advisor — Complete GitHub Package

Upload the CONTENTS of this folder to the root of your GitHub repository.

Required structure:

- index.html
- manifest.webmanifest
- sw.js
- assets/
  - logos/
    - eastwest.png
    - unionbank.png
    - rcbc.png
    - bpi.png
    - bdo.png
    - metrobank.png

Then enable GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root)

The app uses Philippine time (Asia/Manila) for transaction defaults and recommendation calculations.
