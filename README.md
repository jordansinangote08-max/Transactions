# Smart Card Advisor

GitHub Pages-ready package.

## Upload
Upload the contents of this folder to the root of your GitHub repository:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `assets/`

Then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

All transaction defaults use Philippine time (`Asia/Manila`) regardless of device country or VPN.
